# Messaging Automation Map

Checkpoint date: 2026-07-14

All flows are draft-disabled. No Instagram, Manychat, SMS, webhook, keyword, or account integration is configured.

## Optional comment-to-DM drafts

- `PLAN`: disclose that a DM is coming, then offer the planner opt-in.
- `MARINADE`: disclose the DM, then offer the marinade matrix.
- `BANCHAN`: disclose the DM, then offer the banchan checklist.
- `SHOP`: disclose the DM and material connection before linking to an approved on-site gear guide.

Direct-message interaction is not email consent. A user must take a separate explicit action before subscription. Do not buy lists, scrape users, send unsolicited sequences, conceal automation, or place personal identifiers in campaign URLs.

## SMS boundary

SMS is disabled for at least the first 30 days. Any later implementation requires explicit opt-in, legal review, sender identification, quiet-hours handling, suppression, delivery/error handling, and clear STOP/help mechanics before code or provider setup.

## Human approval flow

Keyword match → transparent public reply → permission-aware DM draft → human review of copy/link/disclosure → send → separate opt-in if email is offered → suppression and request handling. Generative output never bypasses approval.
