## Assumptions

- U.S. food-safety guidance is the initial compliance baseline; qualified review is still required before publication.
- English is the initial interface language. Korean language fields remain review-required.
- The deployment target can consume a standard `dist/` static artifact. No hosting account or remote project is assumed.
- Placeholders are intentionally invalid production values and keep the checkpoint non-production.

Any change to a locked decision requires a dated entry explaining the incompatibility, affected contracts, redirects or migrations, and validation rerun.
